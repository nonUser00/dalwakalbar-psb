=========================================
== UI STANDARDIZATION & DESIGN GUIDELINES ==
=========================================
1. KOMPONEN TABEL UTAMA (DataTable)
   - Gunakan komponen @/Components/DataTable.vue untuk semua halaman master/list data.
   - Tabel WAJIB memiliki: Pencarian (Search), Filter Limit (Page per view: 10, 25, 50, 100).
   - Tampilan Tabel harus 'expandable' jika memiliki relasi one-to-many (contoh: Kategori Biaya -> Item Biaya) dengan background child table yang sedikit diredupkan (bg-gray-50).
   - Kolom nomor dan aksi selalu tetap, dengan ukuran yang proporsional.

2. TOMBOL AKSI PADA BARIS (Row Actions)
   - Desktop & Mobile: Gunakan Dropdown component dengan trigger titik tiga (vertical dots) jika aksi lebih dari 2.
   - Isi Dropdown Actions wajib mencakup ikon di sebelah teks (Edit dengan icon pen/pencil text-amber-500, Hapus dengan icon trash text-rose-500, Aktifkan/Nonaktifkan).

3. CHECKBOX LOGIC
   - Jika tabel mendukung Bulk Action, gunakan head checkbox untuk 'Select All' pada page/data yang difilter.
   - Munculkan Floating Bar / Bulk Action button di atas tabel jika ada baris yang dipilih.

4. MODAL
   - Gunakan komponen @/Components/Modal.vue.
   - Ukuran:
     - maxWidth='md' untuk formulir tambah/edit standar (1-4 input).
     - maxWidth='lg' atau maxWidth='2xl' untuk formulir yang kompleks/banyak input.
     - maxWidth='sm' khusus untuk Konfirmasi Hapus (Delete Confirmation).
   - Modal Konfirmasi Hapus WAJIB memiliki icon peringatan besar di tengah (warna merah/rose) dengan teks 'Apakah Anda yakin ingin menghapus data ini?'.
   - Modal Form wajib memiliki header dengan title di sebelah kiri dan tombol close (X) di sebelah kanan. Tombol aksi (Batal & Simpan) selalu berada di bagian bawah dengan border-top.

5. FILTER & PENCARIAN (Search)
   - Pencarian bersifat dinamis/real-time (typing debounce atau enter).
   - Jika ada filter kompleks (Status, Gelombang, Rentang Tanggal), letakkan dalam Dropdown atau Modal Filter khusus di sebelah input pencarian.

6. DESAIN UMUM (Modern, Simpel, Elegan, Mahal)
   - Card/Container: Gunakan ounded-[2rem] atau ounded-2xl tanpa border hitam pekat (gunakan order border-gray-100 dan shadow-sm/shadow-xl yang soft).
   - Warna Utama (Primary): Konsisten di seluruh tombol utama. Tombol PrimaryButton bersudut bulat penuh (ounded-full) dengan efek hover shadow berwarna (shadow-primary/30).
   - Input Form: Menggunakan rounded-xl dengan ring color primary ketika focus.
   - Notifikasi: Toast notification muncul di pojok kanan atas layar menggunakan komponen Toast bawaan layout, hindari desain alert box kaku di dalam page.
   - Animasi: Tambahkan transisi halus (	ransition-all duration-300) pada hover tombol, row tabel, dan tab menu.
